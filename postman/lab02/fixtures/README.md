# Lab02 collection fixtures

These repository-owned fixtures are valid inputs for the Phase 1 multipart upload:

- `valid.png` — `image/png`
- `valid.jpg` — `image/jpeg`
- `valid.gif` — `image/gif`

The collection defaults to `valid.png`. Newman resolves its repository-relative path from the repository root. For Postman Desktop, configure the repository root as the Working Directory and re-select the fixture after importing, or upload the selected fixture to Postman.
