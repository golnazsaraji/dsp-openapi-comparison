# Laboratory Activity 5 - MQTT

The structure of this repository is the following:

- [client](/client) contains the Film Manager client application, implemented in REACT and using MQTT;
- [film-manager-implementation](/film-manager-implementation) contains the Film Manager service implementation, extending the solution of lab04 with MQTT functionalities;
- [mosquitto-configuration-file](/mosquitto-configuration-file) contains the configuration files to use with Eclipse Mosquitto.
- [mqtt_film_message_schema.json](mqtt_film_message_schema.json) is the designed schema representing the format of MQTT messages.
