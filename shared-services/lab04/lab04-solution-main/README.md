# Laboratory Activity 4 - Websocket API

The structure of this repository is the following:

- [client](/client) contains the Film Manager client application, implemented in REACT and using WebSocket API;
- [film-manager-implementation](/film-manager-implementation) contains the Film Manager service implementation, extending the solution of lab01 with WebSocket functionalities;
- [databaseV2.db](databaseV2.db) is the updated SQL database file;
- [ws_message_schema.json](ws_message_schema.json) is the designed schema representing the format of Websocket messages.
